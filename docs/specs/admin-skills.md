# Admin skills

Reuse Skills/UserSkills; no migration or synthetic proficiency levels. Existing `/api/profile/skills` remains unchanged. Add Admin-only `/api/admin/skills` GET (search/category/active/page/pageSize), POST, PUT `/{id}`. Explicit DTO includes ID/name/category/isActive/studentCount; count distinct non-deleted Student accounts. Validate trimmed name 1..100, category null or 0..3; duplicate names (case-insensitive, including inactive) return 409; missing row 404. Serialize catalog writes with a PostgreSQL advisory transaction lock. No deletion of linked records.

Icon upload: Admin-only multipart POST `/api/admin/skills/icons` normalizes valid JPG/PNG/WebP <=5 MB to PNG <=512px and uploads using existing ICloudImageStorage. POST `/api/admin/skills/icons/remove-background` returns a normalized transparent PNG using existing U2NET processor, without changing DB or uploading. One processing operation per process, 429 when busy. Save payload accepts optional IconUrl; omitted preserves current icon, provided URL must be HTTPS Cloudinary image delivery without credentials/query/fragment. No schema change; no arbitrary URL fetching. Frontend selects/previews/restores source, optional background removal, uploads on save with retry cache; Cloudinary secrets remain backend-only.
